# Security Policy

These stress demos are examples for [Datalium Strata](https://github.com/datalium/strata). They aren't meant to be deployed as they are: the Postgres in `docker-compose.yml` has public credentials and keeps nothing.

**Please don't report a security issue in a public issue, discussion or pull request.**

- **A vulnerability in Strata itself:** follow the [Strata security policy](https://github.com/datalium/strata/blob/main/SECURITY.md).
- **A vulnerability in these demos** (a scenario that teaches an unsafe pattern, or a vulnerable dependency): [report it privately](https://github.com/datalium/strata-stress-dotnet/security/advisories/new) from this repository's Security tab, or email [security@datalium.com](mailto:security@datalium.com).

The response times in the Strata security policy apply to both.
